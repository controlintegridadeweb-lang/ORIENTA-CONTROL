## Decisões arquiteturais

Os ADRs vigentes ficam em [`current/decisions/`](./current/decisions/). Eles registram decisões e consequências que continuam válidas; não são um diário de correções.

Documentos de auditoria ou estados substituídos não permanecem no pacote corrente. O histórico de desenvolvimento deve ficar no controle de versão, não misturado à documentação normativa.
